# Concept Crafter Plus - 概念圖編輯器

歡迎使用 **Concept Crafter Plus**！這是一款強大且易於使用的本地端概念圖編輯工具，無需安裝任何軟體，直接使用瀏覽器即可運行。它可以幫助您組織想法、規劃架構，並以視覺化的方式呈現複雜的概念。

## 🚀 快速開始

1. **啟動程式**：直接雙擊打開 `concept-crafter-plus.html` 檔案（建議使用 Chrome 或 Edge 瀏覽器）。
2. **選擇工作區**：點擊左側面板的列表分頁中的 **「開啟專案資料夾」** 按鈕，選擇您電腦上的一個資料夾作為專案儲存位置。所有的地圖檔案都會保存在這個資料夾中。
3. **建立地圖**：再點擊 **「建立新 Map」**，輸入名稱後即可開始。

---

## ✨ 核心功能介紹

### 1. 節點與框架 (Nodes & Frames)

- **建立**：使用工具列按鈕新增「節點」或是「框架」（用於分組）。
- **移動**：直接拖曳節點或框架即可移動位置。
- **編輯內容**：雙擊節點或框架，即可開啟 **進階文字編輯器**。
  - 支援 **粗體**、*斜體*、底線、~~刪除線~~。
  - 可調整文字大小與顏色。
  - 支援清單（項目符號與編號）。
  - 可以插入超連結。

### 2. 連接線 (Connections)

- 建立關聯非常簡單：
    1. 點擊工具列的 **「連接模式」** 按鈕（或相關圖示）。
    2. 點擊起始節點。
    3. 點擊目標節點，連接線即會自動建立。
- 您可以為連接線設定顏色、標籤文字以及箭頭樣式。
- **箭頭類型**：單箭頭、雙箭頭、無箭頭、虛線（註解用）🌟 *New!*

### 3. 多選模式 (Multi-Select Mode)

我們大幅強化了多個物件的選取與操作體驗：

- **開啟/關閉**：點擊工具列的 **「多選模式」** 按鈕。
- **框選操作**：在畫布空白處按住滑鼠左鍵並拖曳，即可拉出選取框。
- **智慧連接線選取**：
  - 當您框選到一條連接線時，系統會**自動選取**該連接線兩端的節點，讓您搬移整組概念時更方便。
  - 我們使用了精確的線段判定技術，只有真正「切過」或「包含」連接線時才會選取，不會再因為誤觸邊界框而選錯。
- **批次操作**：選取多個物件後，您可以一次性進行 **移動**、**複製**、**貼上** 或 **刪除**。

### 4. 復原與重做 (Undo / Redo)

- 做錯了？沒關係！隨時點擊 **「復原」** (Undo) 回到上一步。
- 在多選模式下的操作也完全支援復原功能。

### 5. 未儲存提醒

- **切換專案資料夾時**：若有 Map 尚未儲存，系統會彈出確認對話框，列出所有未儲存的 Map，讓您決定是否要放棄更動。
- **關閉頁面時**：若有未儲存的更動，瀏覽器會顯示離開確認提示，防止您不小心遺失編輯內容。
- **視覺提示**：Map 列表中會顯示「● 已修改」標記，讓您清楚知道哪些 Map 需要儲存。

### 6. 檢視與縮放

- **縮放**：使用滑鼠滾輪可以放大或縮小畫布。
- **平移**：按住滑鼠左鍵（在空白處）拖曳畫布，或使用觸控板平移。

## 📅 更新日誌 (Changelog)

### v1.2.6 (2026-01-27)

- **修正**：修復小型節點（如標籤節點 `isLabel`）連接線無法正確連接到節點邊緣的問題。
- **改進**：移除 `getEdgePoint` 函數中的最小尺寸限制，現在可正確顯示由第三方工具建立的小型標籤節點連接線。

### v1.2.5 (2026-01-25)

- **改進**：Map 列表改用標題 (Title) 作為主要名稱顯示，檔名則顯示為小字副標題。
- **新增**：多選模式支援複製連接線 — 當連接線兩端的節點或框架都被選取時，連接線也會一併複製，貼上時會自動連接到新元素。

### v1.2.4 (2026-01-21)

- **修正**：優化地圖檢視器的觸控互動機制，改用全域點擊偵測 (Hit Testing) 代替 CSS 處理，徹底解決了部分連結節點無法平移的問題。
- **新增**：在桌機模式下，滑鼠懸停於連結節點時會顯示手型游標。

### v1.2.3 (2026-01-21)

- **修正**：徹底修正導出的 Map 檔觸控操作問題 — 節點和框架使用 `pointer-events: none` 讓觸控事件穿透到 container，有連結的節點保持可點擊。
- **移除**：移除有超連結節點的 🔗 emoji 圖標。

### v1.2.1 (2026-01-20)

- **修正**：修正觸控操作問題 — 現在觸碰節點或框架時也能正常平移/縮放，不再被元素攔截。
- **改進**：有連結的節點仍然保持可點擊。

### v1.2.0 (2026-01-19)

- **新增**：節點屬性新增「標籤樣式」選項，可將節點套用緊湊標籤樣式（適用於連接線拐點標籤）。
- **改進**：`isLabel` 屬性直接存儲於 JSON 中，簡化資料結構。

### v1.1.4 (2026-01-18)

- **修正**：修復節點標籤顯示模式 (Label View) 的可見性問題，確保在編輯器與匯出的 Map 中都能正確顯示。

## 💡 小撇步

- **獨立檢視**：儲存後的 HTML 檔案可以單獨打開檢視，不需要依賴主程式，方便分享給他人。
- **自訂圖示**：您可以在專案資料夾中放入一個名為 `concept-crafter_icon.png` 的圖片檔案。如此一來，生成的 HTML 地圖檔案就會自動使用該圖片作為瀏覽器分頁的圖示（Favicon）。
- **觸控支援**：本程式支援觸控螢幕操作，您可以在平板電腦上使用手指拖曳、縮放。
