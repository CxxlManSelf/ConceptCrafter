## 🎓 實用範例：概念圖 vs 傳統筆記

### 範例 1：學習 JavaScript —— 發現隱藏的知識連結

**❌ 傳統筆記（線性、分離）：**
```
1. 變數（let, const, var）
2. 函式（function, arrow function）
3. Promise（then, catch）
4. DOM 操作（querySelector, addEventListener）
```
→ 看起來是四個獨立主題，學完就忘

**✅ 概念圖（網狀、連結）：**
```
         [閉包(Closure)] ←─影響─┐
               ↓                 |
          [變數作用域]          |
               ↓                 |
         [事件監聽器] ──需要──→ [函式]
               ↓                 ↓
         [DOM 操作] ←─回傳─ [Promise] ──解決─→ [非同步問題]
               ↓                 ↑                    ↑
         [querySelector]    [fetch API]          [Callback Hell]
               ↓                 ↓                    |
         [返回 Node] ──可用於→ [事件處理] ──會產生──┘
```

**概念圖的威力**：
- 💡 發現：**事件監聽器需要理解閉包**，否則會遇到變數作用域問題
- 💡 理解：**Promise 解決的是 Callback Hell**，而非憑空出現的語法
- 💡 連結：**DOM 操作、非同步、函式**三者環環相扣，一起學效果更好
- 🎯 **學習路徑清晰**：先學函式 → 理解閉包 → 再學事件監聽，不會卡關！

### 範例 2：電商專案規劃 —— 發現依賴與風險

```
    [會員系統] ──必須先有──→ [購物車功能] ──依賴──→ [訂單系統]
         ↓                        ↓                    ↓
    [身份驗證] ←─共用─→ [Session管理] ←─共用─→ [金流API]⚠️
         ↓                        ↓                    ↓
```

## 🚀 快速開始

### 1. 開啟工具
雙擊 `concept-crafter.html` 檔案，用瀏覽器開啟即可！

**建議瀏覽器**：Chrome、Edge（支援專案資料夾功能）

### 2. 選擇專案資料夾（可選）
點擊「選擇專案資料夾」按鈕，選擇一個資料夾來存放你的所有概念圖。

> **提示**：Firefox/Safari 用戶可以直接使用「新增 Map」和「載入 Map」功能。

### 3. 創建你的第一個概念圖

1. **新增節點**：點擊「新增節點」，在畫布上點擊任意位置
2. **編輯內容**：雙擊節點編輯內容，支援富文本格式
3. **建立連結**：點擊「連接模式」，依序點擊兩個節點建立連結
4. **加入框架**：點擊「新增 Frame」圈選相關概念
5. **儲存 Map**：右鍵點擊側邊欄的 Map，選擇「儲存 Map」

## 🎮 操作指南

### 基本操作
| 操作 | 方法 |
|------|------|
| 新增節點 | 點擊工具列「新增節點」→ 點擊畫布 |
| 移動節點 | 拖曳節點 |
| 編輯節點 | 雙擊節點 |
| 刪除節點 | 右鍵節點 → 刪除 |
| 複製節點 | Ctrl+C（選中節點後） |
| 貼上節點 | Ctrl+V |
| 多選元素 | 點擊「選取模式」→ 點擊多個元素 |
| 批次移動 | 選取模式下拖動任一已選元素 |
| 批次複製/刪除 | 選取多個元素 → 右鍵 → 選擇操作 |
| 縮放畫布 | 滑鼠滾輪 |
| 平移畫布 | 拖曳空白處（非選取模式） |

### 進階功能
- **選取模式**：點擊工具列「選取模式」按鈕，可同時選取多個節點和 Frame，支援批次搬移、複製、刪除。選取的元素會顯示紫色高亮邊框
- **連結功能**：點擊「連結」按鈕開啟連結編輯對話框，可輸入連結網址和連結文字。如果事先選取了文字，該文字會自動填入連結文字欄位
- **調整節點大小**：拖曳節點右下角的小三角
- **更改節點顏色**：右鍵節點 → 變更顏色（支援藍、綠、紅、橙、紫、灰）
- **設定文字對齊**：右鍵節點 → 文字對齊（靠左、置中、靠右）
- **設定節點狀態**：右鍵節點 → 標記完成/放棄
- **設定 Frame 狀態**：右鍵 Frame → 標記完成/放棄（與節點狀態標記功能相同）
- **建立雙向連結**：連接模式下，點擊已有連結的兩個節點
- **HTML 原始碼**：點擊「< > HTML」按鈕切換至 HTML 原始碼編輯模式，直接編輯 HTML 代碼

### 超連結功能
節點中可以加入三種連結：
1. **外部連結**：`https://example.com` - 在新分頁開啟
2. **專案內部連結**：`./file.html` 或 `/path/file.html` - 在當前頁面開啟
3. **特殊功能連結**：
   - `javascript:history.back()` - 返回上一頁
   - `#anchor` - 跳到錨點

## 💡 最佳實踐

### 1. 由上而下建構
從核心概念開始，逐層展開細節。這樣能保持結構清晰。

### 2. 使用顏色分類
不同主題用不同顏色，例如：
- 🔵 藍色：基礎概念
- 🟢 綠色：已掌握的知識
- 🟠 橙色：重要但困難的部分
- 🔴 紅色：需要加強的區域
- 🟣 紫色：進階主題
- ⚪ 灰色：參考資料或次要內容

### 3. 適當使用 Frame
將相關概念用 Frame 圈起來，讓視覺層次更分明。但不要過度使用，3-5 個 Frame 最理想。

### 4. 定期更新
概念圖是活的！隨著學習進度，持續更新和完善你的概念圖。

### 5. 善用狀態標記
學習計畫中，用 ✅ 標記已完成的概念，用 ❌ 標記決定跳過的部分。

## 🙋 常見問題

**Q: 為什麼不能選擇資料夾？**
A: 請使用 Chrome 或 Edge 瀏覽器。Firefox 和 Safari 目前不支援 File System Access API，但你仍可以使用「新增 Map」和「載入 Map」功能。

**Q: 資料會遺失嗎？**
A: 每次修改後，系統會提醒你儲存。只要記得儲存，資料就不會遺失。建議養成 Ctrl+S 的習慣！

**Q: 可以匯出為圖片嗎？**
A: 目前版本暫不支援，但你可以使用截圖工具（如 Windows 的剪取工具）截取畫面。

**Q: 可以多人協作嗎？**
A: 目前是單機版本，但你可以透過版本控制系統（如 Git）來實現多人協作。

**Q: 檔案可以跨版本使用嗎？**
A: 可以！每個 HTML 檔案包含完整的程式碼，即使 ConceptCrafter 未來升級，舊檔案依然可以正常開啟。
