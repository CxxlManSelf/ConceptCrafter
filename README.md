## 🎓 實用範例：概念圖 vs 傳統筆記

### 範例 1：學習 JavaScript —— 發現隱藏的知識連結

**❌ 傳統筆記（線性、分離）：**
```
1. 變數（let, const, var）
2. 函式（function, arrow function）
3. Promise（then, catch）
4. DOM 操作（querySelector, addEventListener）
```
→ 看起來是四個獨立主題，學完就忘

**✅ 概念圖（網狀、連結）：**
```
         [閉包(Closure)] ←─影響─┐
               ↓                 |
          [變數作用域]          |
               ↓                 |
         [事件監聽器] ──需要──→ [函式]
               ↓                 ↓
         [DOM 操作] ←─回傳─ [Promise] ──解決─→ [非同步問題]
               ↓                 ↑                    ↑
         [querySelector]    [fetch API]          [Callback Hell]
               ↓                 ↓                    |
         [返回 Node] ──可用於→ [事件處理] ──會產生──┘
```

**概念圖的威力**：
- 💡 發現：**事件監聽器需要理解閉包**，否則會遇到變數作用域問題
- 💡 理解：**Promise 解決的是 Callback Hell**，而非憑空出現的語法
- 💡 連結：**DOM 操作、非同步、函式**三者環環相扣，一起學效果更好
- 🎯 **學習路徑清晰**：先學函式 → 理解閉包 → 再學事件監聽，不會卡關！

## 🚀 快速開始

### 1. 安裝應用程式
```bash
# 安裝依賴
npm install

# 啟動應用程式
npm start

# 打包應用程式（可選）
npm run build
```

### 2. 選擇專案資料夾
點擊「選擇專案資料夾」按鈕，會顯示**最近開啟的專案**列表：
- **點擊專案**：直接開啟該專案
- **選擇其他資料夾**：瀏覽選擇新的專案資料夾
- **移除專案**：從最近列表中移除

> **提示**：最近專案列表會自動記錄最近開啟的 10 個專案，重啟應用程式後仍然保留。

### 3. 創建你的第一個概念圖

1. **新增 Map**：點擊「新增 Map」，輸入標題和檔名（檔名可選，留空則使用標題）
2. **新增節點**：點擊「新增節點」，在畫布上創建節點
3. **編輯內容**：右鍵點擊節點選擇「編輯文字」，支援富文本格式
4. **建立連結**：點擊「連接模式」，依序點擊兩個節點建立連結
5. **加入框架**：點擊「新增 Frame」圈選相關概念
6. **儲存 Map**：在右側面板的 Map 列表中點擊「儲存」按鈕

> **注意**：選擇專案資料夾後不會自動載入檔案，需要手動建立新 Map 或載入現有檔案。

### 進階功能
- **節點連結功能**：右鍵節點 → 編輯連結，可為節點設定超連結。在生成的 map 檔案中點擊節點即可導航。專案內 HTML 在同視窗開啟，外部連結在新視窗開啟
- **調整節點大小**：拖曳節點右下角的小三角
- **更改節點顏色**：右鍵節點 → 變更顏色（支援藍、綠、紅、橙、紫、灰）
- **設定文字對齊**：右鍵節點 → 文字對齊（靠左、置中、靠右）
- **設定節點狀態**：右鍵節點 → 標記完成/放棄
- **設定 Frame 狀態**：右鍵 Frame → 標記完成/放棄（與節點狀態標記功能相同）
- **建立雙向連結**：連接模式下，點擊已有連結的兩個節點
- **選取模式**：點擊工具列「選取模式」按鈕，可同時選取多個節點、Frame 和連接線，支援批次搬移、複製、刪除。選取的節點和 Frame 會顯示紫色高亮邊框，選取的連接線會以紫色粗線顯示
- **HTML 原始碼**：需要更精細的控制？點擊「< > HTML」按鈕切換至 HTML 原始碼編輯模式
- **連結功能**：點擊「連結」按鈕開啟連結編輯對話框，可輸入連結網址和連結文字。如果事先選取了文字，該文字會自動填入連結文字欄位

### 超連結功能
節點中可以加入三種連結：
1. **外部連結**：`https://example.com` - 在新分頁開啟
2. **專案內部連結**：`./file.html` 或 `/path/file.html` - 在當前頁面開啟
3. **特殊功能連結**：
   - `javascript:history.back()` - 返回上一頁
   - `#anchor` - 跳到錨點

## 💡 最佳實踐

### 1. 由上而下建構
從核心概念開始，逐層展開細節。這樣能保持結構清晰。

### 2. 使用顏色分類
不同主題用不同顏色，例如：
- 🔵 藍色：基礎概念
- 🟢 綠色：已掌握的知識
- 🟠 橙色：重要但困難的部分
- 🔴 紅色：需要加強的區域
- 🟣 紫色：進階主題
- ⚪ 灰色：參考資料或次要內容

### 3. 適當使用 Frame
將相關概念用 Frame 圈起來，讓視覺層次更分明。但不要過度使用，3-5 個 Frame 最理想。

### 4. 定期更新
概念圖是活的！隨著學習進度，持續更新和完善你的概念圖。

### 5. 善用狀態標記
學習計畫中，用 ✅ 標記已完成的概念，用 ❌ 標記決定跳過的部分。

## 🙋 常見問題

**Q: 最近專案列表儲存在哪裡？**
A: 儲存在應用程式的 localStorage 中。Windows 位置：`%APPDATA%\concept-crafter\Local Storage\`，macOS：`~/Library/Application Support/concept-crafter/Local Storage/`。資料會永久保存，除非手動清除或卸載應用程式。

**Q: 為什麼選擇專案後沒有自動載入檔案？**
A: 這是設計上的選擇。你需要手動點擊「新增 Map」或「載入 Map」來管理檔案，這樣可以更精確地控制工作環境。

**Q: 資料會遺失嗎？**
A: 每次修改後，系統會顯示「儲存」按鈕提醒你。只要記得儲存，資料就不會遺失。

**Q: 可以匯出為圖片嗎？**
A: 目前版本暫不支援，但你可以使用系統截圖工具（Windows：Win+Shift+S，macOS：Cmd+Shift+4）截取畫面。

**Q: 可以多人協作嗎？**
A: 目前是單機版本，但你可以透過版本控制系統（如 Git）來實現多人協作。建議將專案資料夾加入 Git 版控。

**Q: 儲存的 HTML 檔案可以在瀏覽器開啟嗎？**
A: 可以！每個儲存的 HTML 檔案都包含完整的瀏覽器功能，可以在任何現代瀏覽器中開啟檢視，支援縮放、平移等互動操作。

**Q: 如何在不同電腦間同步專案？**
A: 將專案資料夾放在雲端同步服務（如 Dropbox、OneDrive、Google Drive）中，或使用 Git 版本控制。注意：最近專案列表是本地儲存，不會自動同步。
