Concept Crafter 使用說明

📌 基本功能

  • 新增節點：點擊「新增節點」按鈕後，在畫布上點擊位置即可建立節點
  • 新增連接：點擊「新增連接」後，先點擊起始節點，再點擊目標節點即可建立連接
  • 新增 Frame：點擊「新增 Frame」後，在畫布上點擊位置即可建立 Frame 分組
  • 選擇工具：用於選擇、移動和編輯元素

🎨 編輯元素

  • 編輯節點文字：雙擊節點即可進入編輯模式，修改文字內容
  • 移動元素：選擇模式下，拖動節點或 Frame 即可移動
  • 調整大小：在節點或 Frame 右下角拖動調整手柄可改變大小
  • 添加超連結：雙擊節點進入編輯模式，選擇文字後點擊「添加超連結」按鈕

🗺️ Map 管理

  • 新增 Map：點擊左邊「新增 Map」按鈕建立新的概念地圖
  • 儲存 Map：點擊「儲存 Map」按鈕將當前地圖儲存為 HTML 檔案
  • 載入 Map：點擊左邊列表中的 Map 即可切換，或使用「從單一檔案載入」上傳 HTML 檔案
  • 修改標記：Map 名稱後的 * 表示有未儲存的變更

🎛️ 視圖控制

  • 縮放：使用滑鼠滾輪縮放，或點擊右下角的 🔍+ 和 🔍- 按鈕
  • 平移：按住空白鍵再拖動滑鼠，或使用滑鼠中鍵平移
  • 重置視圖：點擊「重置視圖」按鈕回到原始位置

💾 檔案系統

  • 選擇專案資料夾：可在 Chrome/Edge/Opera 瀏覽器中選擇本地資料夾，直接管理 Map 檔案
  • 從資料夾重新整理：重新掃描專案資料夾中的 Map 檔案

✨ 提示

  • 每個元素都可在右邊屬性面板中進行詳細設定（顏色、大小、標籤等）
  • 連接線可以設定標籤和是否顯示箭頭
  • Frame 可用於組織和分組相關的節點
