Concept Crafter 使用說明

系統需求

  • 建議瀏覽器：Chrome 86+、Edge 86+、Opera 72+
  • 原因：本應用程式使用 File System Access API 來讀取和儲存檔案。這是一個較新的網頁標準，目前只有基於 Chromium 的瀏覽器完整支援。
  • Firefox/Safari 用戶：目前這些瀏覽器不支援「選擇專案資料夾」功能。
  • 檢視 map：所有現代瀏覽器（包括 Firefox、Safari）都可以正常開啟和檢視已儲存的 .html map 檔案。

1. 開始使用

  • 選擇專案資料夾：點擊左上角的按鈕選擇一個資料夾。這是為了讓瀏覽器有權限讀取和儲存您的 map 檔案。
  • 建立/載入 Map：選擇資料夾後，您可以建立新的 map 或載入現有的 .html map 檔。

2. 基本操作

  • 新增節點/Frame：使用上方工具列按鈕新增內容。
  • 移動：直接拖曳節點或 Frame。
  • 調整大小：拖曳節點或 Frame 右下角的調整手柄。
  • 縮放與平移：使用滑鼠滾輪縮放，按住滑鼠左鍵拖曳背景可平移畫布。即使滑鼠移出畫布區域，仍可繼續操作。
  • 複製與貼上：右鍵點擊節點或 Frame 選擇「複製」，或使用 Ctrl+C。貼上可使用 Ctrl+V 或在空白處右鍵選擇「貼上」。
  • 右鍵選單：在節點、Frame 或連接線上點擊右鍵，可進行編輯、複製、刪除、變更顏色、文字對齊（節點）或狀態標記（節點/Frame）。
  • 狀態標記：節點和 Frame 都支援狀態標記功能。右鍵選擇「標記為完成」或「標記為放棄」，已標記的元素會在右上角顯示徽章（✓ 完成 / ✗ 放棄）。

3. 編輯內容

  • 編輯文字：右鍵點擊節點選擇「編輯文字」。
  • 富文字編輯：支援 標題 (H1/H2)、列表、縮排、粗體/斜體/底線/刪除線、顏色 以及 超連結。
  • 列表與縮排：
    • 無序列表 (• List)：建立圓點符號列表
    • 有序列表 (1. List)：建立數字編號列表
    • 增加縮排 (→ 縮排)：增加段落或列表項目的縮排層級
    • 減少縮排 (← 減排)：減少段落或列表項目的縮排層級
  • HTML 原始碼：點擊「< > HTML」按鈕可切換至 HTML 原始碼編輯模式，直接編輯 HTML 代碼。
  • 連結功能：
    • 建立連結：點擊工具列的「連結」按鈕，會開啟連結編輯對話框。對話框包含兩個欄位：
      • 連結網址：輸入目標網址或路徑（必填）
      • 連結文字：輸入顯示的文字（選填）
      如果事先選取了文字，該文字會自動填入連結文字欄位。若未選取文字且未輸入連結文字，則使用網址作為顯示文字。
    • 專案內 HTML：使用相對路徑的 HTML 文件（如 ./page.html、doc.htm）會在同一視窗開啟，方便專案內導覽。
    • 其他連結：HTTP/HTTPS 網址、絕對路徑、圖片檔案等都會在新視窗開啟。
    • 特殊功能連結：
      • javascript:history.back() - 回到上一頁
      • javascript:history.forward() - 前往下一頁
      • #section-name - 跳到頁面內的錨點（需配合 HTML id 屬性使用）

4. 連接與關聯

  • 建立連接：點擊「連接模式」按鈕（變紅色），然後依序點擊兩個物件即可建立連線。完成後請再次點擊按鈕取消模式。
  • 編輯連線：右鍵點擊連線可編輯標籤文字或更改箭頭樣式（單向/雙向/無）。

5. 選取模式（多選功能）

  • 啟用選取模式：點擊工具列的「選取模式」按鈕（按鈕會變紅色），進入多選模式。
  • 選取元素：在選取模式下，點擊節點或 Frame 即可選取。選取的元素會顯示紫色高亮邊框。
  • 多選：可以點擊多個節點和 Frame，建立選取集合。
  • 取消選取：
    • 點擊已選取的元素：從選取集合中移除
    • 點擊空白處：清除所有選取
    • 關閉選取模式：自動清除所有選取
  • 批次操作：
    • 批次搬移：點擊任一已選取的元素並拖動，所有選取的元素會一起移動
    • 批次複製：選取多個元素後，右鍵點擊任一選取的元素，選擇「複製選取的元素」
    • 批次刪除：選取多個元素後，右鍵點擊任一選取的元素，選擇「刪除選取的元素」
  • 注意事項：
    • 在選取模式下，點擊空白處不會平移畫布（需要先關閉選取模式）
    • 選取模式適合處理大量元素時使用

6. Map 管理

  • 多 Map 支援：可以同時開啟多個 map 進行編輯，在右側面板切換。
  • 獨立視圖：每個 map 會記住自己的視圖位置和縮放級別，切換 map 時會自動恢復上次的視圖狀態。
  • 修改 Map 資訊：在右側面板的 Map 列表中，點擊「修改」按鈕可編輯 Map 標題。檔案名稱欄位可複製但不可修改，確保檔案完整性。修改標題後需儲存才會更新。
  • 儲存：在右側面板的 Map 列表中，點擊「儲存」按鈕。有未儲存變更的 map 會顯示「儲存」按鈕。
  • 標題格式保留：系統會智能保留第三方工具建立的 Map 檔案標題格式，確保相容性。

7. 分享與協作

  • 獨立瀏覽：儲存後的 .html 檔案包含獨立瀏覽器。您可以直接將檔案傳給他人，他們只需用瀏覽器打開即可觀看並操作縮放/平移，無需安裝任何軟體。
  • 跨 Map 複製：可以在不同 map 之間複製貼上節點和 Frame，方便重複使用內容。

8. 鍵盤快捷鍵

  • Ctrl+C：複製選取的節點或 Frame（需先右鍵點擊選取）
  • Ctrl+V：貼上複製的內容

9. 快捷提示

  • 組織架構：使用 Frame 來將相關的節點群組在一起，建立清晰的視覺層次。
  • 顏色管理：使用不同顏色的節點來區分不同類型的概念或狀態。節點支援藍、綠、紅、橙、紫、灰六種顏色。
  • 文字對齊：節點支援靠左、置中、靠右三種文字對齊方式，可透過右鍵選單設定。
  • 連接線標籤：為連接線添加標籤可以說明節點之間的關係（例如：「繼承自」、「依賴於」等）。
  • 流暢操作：平移和縮放時，即使滑鼠移出畫布區域也能繼續操作，不會中斷。
